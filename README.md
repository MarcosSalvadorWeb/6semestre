## Arquivos Quarto (.qmd)

Alguns documentos deste repositório foram desenvolvidos utilizando **Quarto** (`.qmd`).

Para gerar automaticamente os apêndices contendo os códigos utilizados, é necessário instalar a extensão **code-appendix**. Após instalar o Quarto em sua máquina, execute o seguinte comando no terminal:

```bash
quarto add cl-roberts/code-appendix
```

> **Observação:** Certifique-se de que o Quarto esteja instalado antes de executar o comando acima.
